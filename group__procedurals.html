Detailed Description

Procedural generation building blocks.

Noise, Poisson disk sampling, smoothing, and a TinyKeep-style dungeon generator. Deterministic : same seed, same output.

2D deterministic value noise in [-1, 1].

Computes smooth pseudo-random noise from (x, y) and an optional seed. Values at the four surrounding grid points are hashed and smoothly interpolated using an ease-in-out curve.
